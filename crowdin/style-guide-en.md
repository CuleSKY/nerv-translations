# English style guide

The published guide this follows: the [Microsoft Writing Style Guide](https://learn.microsoft.com/en-us/style-guide/welcome/). Where this page is silent, that guide decides. The register is the written one of a mature product: plain, direct, never colloquial.

## Writing

- Sentence case for labels, titles, buttons and menu items: "Sign in", "Map changed", not "Sign In".
- No full stop at the end of a label, a title or a server or map name. A full sentence ends with one.
- Use the serial comma. Write numbers as numerals.
- Address the player as "you" when the text speaks to them; do not use "we" for the site.
- Verbs for actions ("Sign in", "Copy address"), nouns for places and things ("Settings", "Favourites").
- Say the same thing with the same word: follow the glossary. Never vary a term for style.

## Spelling

The site's interface already writes "Favourites" (British spelling); the glossary follows the interface until the maintainer says otherwise. **To confirm:** British or American spelling for all new English text.

## Names

- A server's name is a proper name, not a sentence. Keep the community's name and abbreviation in Latin letters (EXG, ZombiEden, FYS, UB). Write the rest as the existing naming rules do: "ZombiEden CS2 KZ Hard #3", "EXG Zombie Escape #5", "FYS CSGO Surf #2 Beginner".
- Game and mode names stay as players write them: ZE, KZ, Bhop, CS2, CSGO, Tier, TP, PRO, NUB. Game modes that have an English name take it: Zombie Escape, Mini-Games, Surf, Prop Hunt, Beast Deathmatch.
- Map names: the map's code written as a name. Drop the mode prefix (`ze_`) and the author's or porter's tag, replace underscores with spaces, capitalise each word, keep the version and the joke. Write the version so it reads at a glance: `ze_frozen_abyss_v1_2` is "Frozen Abyss (v1.2)", `ze_drakelord_castle_b3` is "Drakelord Castle (Beta 3)". If the map has a published English title, use it.
- A label or a tag is a short noun: "Gear", "Hot", "Classic", "Stages".

## Reminders and messages

- One short complete phrase per line, as the Simplified Chinese source has it: "Map: {map}", "Current players: {players} / {capacity}".
- Keep every `{variable}`. Do not translate a variable's name.
- Quotation marks: curly double quotation marks; punctuation outside them unless it belongs to the quotation.
