# 한국어 스타일 가이드

따르는 공개 가이드: [Microsoft Korean Style Guide](https://learn.microsoft.com/ko-kr/style-guide/welcome/). 이 문서에 없는 사항은 해당 가이드를 따릅니다. 문체는 성숙한 제품의 문어체이며, 구어체나 장난스러운 표현은 쓰지 않습니다.

## 문체

- 문장(메시지)은 합니다체로 씁니다. 예: "맵이 변경되었습니다". 해요체는 쓰지 않습니다.
- 레이블, 버튼, 메뉴, 제목은 명사 또는 명사구로 끝맺습니다. 예: "설정", "즐겨찾기". 레이블 끝에는 마침표를 붙이지 않습니다.
- 문장 끝에는 마침표를 붙입니다.
- 같은 뜻에는 같은 낱말을 씁니다. 용어집을 따르고, 문체를 위해 바꿔 쓰지 않습니다.

## 표기

- 띄어쓰기를 지킵니다. 숫자와 알파벳은 반각으로 씁니다.
- 괄호와 구두점은 반각을 쓰고, 서버 이름에서는 기존 명명 규칙의 표기를 따릅니다. 예: "Mapeadores CS2 좀비 탈출 (유럽)", "RSS KZ 초급반 (1~4티어)".
- 외래어는 국립국어원의 표기를 따릅니다: 서버, 맵, 로비.

## 이름

- 서버 이름은 고유 명사입니다. 커뮤니티 이름과 약칭은 원문 그대로 알파벳으로 씁니다(EXG, ZombiEden, FYS, UB). 나머지를 한국어로 씁니다. 예: "ZombiEden CS2 KZ 고급 #3", "EXG 좀비 탈출 #5".
- 플레이어가 영어로 말하는 게임 용어는 번역하지 않습니다: ZE, KZ, Bhop, CS2, CSGO, Tier, TP, PRO, NUB. 한국어 이름이 있는 모드는 용어집을 따릅니다: 좀비 탈출, 미니게임, 서핑, 숨바꼭질, 비스트 데스매치.
- 맵 이름: 맵 코드를 이름으로 씁니다. 한국어로 알려진 정식 제목(게임, 영화, 애니메이션, 지명 등)이 있으면 그것을 씁니다. 없으면 코드가 나타내는 영어 이름(접두사 `ze_`와 제작자·이식자 표기를 빼고, 밑줄은 공백으로, 각 단어는 대문자로 시작하고, 버전과 말장난은 남깁니다)을 알파벳 그대로 씁니다. 음역을 지어내지 않습니다.
- 레이블과 태그는 짧은 명사로 씁니다: "장비", "인기", "클래식".

## 알림과 메시지

- 원문과 같은 길이의 짧은 문장 또는 명사구로 씁니다: "맵: {map}", "현재 인원: {players} / {capacity}".
- `{변수}`는 한 글자도 바꾸지 않습니다.
